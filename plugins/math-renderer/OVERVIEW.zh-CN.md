Math Renderer 在已完成的 assistant 回复中，把块级和行内 LaTeX 公式排版成图片。块级公式带有 Show LaTeX 和 Copy LaTeX 操作；点击行内公式可以查看它的源码。这是实验性的 beta 版本，要求 app 和 daemon 都是 Paseo 0.9.0-beta.1 或更新版本。

渲染在 daemon 主机上完成，使用 MathJax 和内置的 resvg WASM 模块，不使用外部渲染服务。回复在流式输出时保持原生显示，回复完成后公式才会出现。

**限制：**

- 在 Paseo 0.11 网页客户端中，页面重新加载后，最新一条回复会保持原生显示，直到下一轮对话，因为 Paseo 把它报告为仍在流式输出。
- 含有表格、图片或 HTML 的回复会整条保持原生显示，非常长的回复也一样。
- 匹配的回复由插件自己的简单 Markdown 渲染器绘制，所以代码高亮、工作区文件交互和原生文本选择没有完全复现。不要和其他替换 assistant 消息的插件一起使用。
- 聊天查找（Find）无法搜索公式源码。在 Paseo 0.12 之前，它也无法可靠地跳转到已渲染的回复。Command Center 里有一个操作可以切换回原生回复。
- 自动化检查在 Paseo 0.13.2 SDK 下通过，最近一次实测是在 Paseo 0.13.2 daemon 和 0.13.2 网页客户端上。原生 iOS 和 Android 尚未确认测试通过。
