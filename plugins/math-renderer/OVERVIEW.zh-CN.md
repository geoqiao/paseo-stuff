Math Renderer 在已完成的 assistant 回复中，把块级和行内 LaTeX 公式排版成图片。块级公式带有 Show LaTeX 和 Copy LaTeX 操作；点击行内公式可以查看它的源码。这是实验性的 beta 版本，要求 app 和 daemon 都是 Paseo 0.13.0 或更新版本。

渲染在 daemon 主机上完成，使用 MathJax 和内置的 resvg WASM 模块，不使用外部渲染服务。回复在流式输出时保持原生显示，回复完成后公式才会出现。回复中不含公式的部分，例如表格、图片和代码，继续使用 Paseo 自己的 Markdown 渲染。

**限制：**

- 含有公式的段落、列表和引用由插件自己的简单 Markdown 渲染器绘制，所以这些部分没有代码高亮、工作区文件链接和原生文本选择。不要和其他替换 assistant 消息的插件一起使用。
- 如果同一个段落或列表里既有公式，又有图片、表格或 HTML，整条回复会保持原生显示，非常长的回复也一样。
- 聊天查找（Find）可以找到已渲染回复中的文字，但找不到公式源码。Command Center 里有一个操作可以切换回原生回复来搜索公式源码。
- 已在 Paseo 0.13.2 daemon 和 0.13.2 网页客户端上测试。桌面 app 和原生 iOS、Android 尚未确认测试通过。
